# ניתוב: Dijkstra, Distance Vector ו-BGP

> 🔑 **בשורה אחת:** אלגוריתם ניתוב מחפש מסלול בעלות מינימלית בגרף. **Link State** (Dijkstra) מניח שכל נתב מכיר את כל הגרף. **Distance Vector** (Bellman-Ford) נשען רק על שכנים. בין רשתות אוטונומיות פועל **BGP**, והוא מחליט לפי **מדיניות**, לא לפי הדרך הקצרה ביותר.

## מה המבחן שואל

- **שחזור משקלי קשתות מטבלת Dijkstra:** 25A-A שאלה 5.
- **צעד Relaxation יחיד** ב-Dijkstra: 26A-A שאלה 13.
- **מה "נתיב טוב"** ומה העלות: 25A-B שאלה 11.
- **מה מנחה את BGP** בבחירת נתיב: 26A-A שאלה 12.
- הנושא מופיע בשאלה או שתיים בלבד בכל מבחן, ולכן מספיק לשלוט במכניקה של שלב Dijkstra אחד ובעיקרון של BGP.

## הגדרות

- **גרף:** צמתים (נתבים) וקשתות עם **עלות**. העלות היא משקל **מופשט** שנקבע לפי מדיניות: יכול לייצג השהיה, רוחב פס, מספר קפיצות או כל מטריקה אחרת. לכן "נתיב טוב" אינו "תמיד המהיר" או "תמיד הקצר" אלא נתיב בעל **עלות מינימלית** (25A-B שאלה 11).
- **Link State:** כל נתב מקבל את מצב כל הקישורים (flooding), ומחשב לבד מסלולים קצרים בעזרת Dijkstra. OSPF הוא Link State, בתוך רשת אוטונומית.
- **Distance Vector:** כל נתב מכיר רק שכנים ושולח להם את וקטור המרחקים שלו.

## Dijkstra

מחשבים מצומת מקור את המרחק המינימלי לכל השאר. מסמנים:
- $D(v)$ המרחק הנוכחי לצומת $v$, ‏$p(v)$ הצומת הקודם בנתיב, ‏$N'$ הצמתים שמרחקם סופי.

**אלגוריתם:**
1. אתחול: $N'=\{src\}$. לשכנים $D(v)=c(src,v)$ ולשאר $\infty$.
2. חוזרים: בוחרים $w\notin N'$ עם $D(w)$ מינימלי, מוסיפים ל-$N'$, ולכל שכן $v\notin N'$ של $w$ מעדכנים (**relaxation**):
$$D(v)=\min\{D(v),\;D(w)+c(w,v)\}$$
3. עד שכל הצמתים ב-$N'$.

**דוגמה** (גרף עם הקשתות $u$-$v$ ‏2, $u$-$x$ ‏1, $u$-$w$ ‏5, $v$-$x$ ‏2, $v$-$w$ ‏3, $x$-$w$ ‏3, $x$-$y$ ‏1, $w$-$y$ ‏1, $w$-$z$ ‏5, $y$-$z$ ‏2), מקור $u$:

| צעד | $N'$ | $D(v),p$ | $D(w),p$ | $D(x),p$ | $D(y),p$ | $D(z),p$ |
|---|---|---|---|---|---|---|
| 0 | $u$ | 2, u | 5, u | 1, u | $\infty$ | $\infty$ |
| 1 | $ux$ | 2, u | 4, x | | 2, x | $\infty$ |
| 2 | $uxv$ | | 4, x | | 2, x | $\infty$ |
| 3 | $uxvy$ | | 3, y | | | 4, y |
| 4 | $uxvyw$ | | | | | 4, y |
| 5 | $uxvywz$ | | | | | |

המרחקים הסופיים מ-$u$: $x=1$, ‏$v=2$, ‏$y=2$, ‏$w=3$, ‏$z=4$. (בשוויון $D(v)=D(y)=2$ בוחרים לפי כלל קבוע, התוצאה זהה.)

**צעד relaxation (26A-A שאלה 13):** $D(V)=5$, ‏$D(W)=10$ וקשת $V$-$W$ במשקל 3. אחרי בחינת $V$: $D(W)=\min\{10,5+3\}=8$. ערך 13 מתקבל מחיבור שגוי של 10 ו-3, ערך 10 הוא הישן, ו-3 הוא משקל הקשת בלבד.

### מתכון: משקל קשת מתוך טבלת Dijkstra (25A-A שאלה 5)

אם בטבלה $v$ הגיע דרך $p(v)=a$, אז $c(a,v)=D(v)-D(a)$. בשאלה הטבלה היא מהמקור $v$: $D(u)=4$ (קשת ישירה מהמקור), ‏$D(w)=5$ עם קודם $u$, ולכן $Y=5-4=1$. ‏$D(y)=9$ עם קודם $w$, ולכן $X=9-5=4$. בדיקה שה-$w$ באמת הקודם של $y$: דרך $x$ היה $5+5=10>9$ ודרך $z$ היה $6+4=10>9$. אם קשת אינה נמצאת על שום נתיב בעץ, אי אפשר לדעת את משקלה אלא רק חסם: זו התשובה "אי אפשר לקבוע".

## Distance Vector

משוואת Bellman-Ford:
$$D_x(y)=\min_{v}\{c(x,v)+D_v(y)\}$$
כאשר המינימום על כל שכני $x$. כל נתב שולח לשכניו את הוקטור שלו כשהוא משתנה, ומחשב מחדש. התהליך מתכנס בערכים הנכונים.

**דוגמה:** באותו גרף, $x$ מכיר ישירות $u=1$, ‏$v=2$, ‏$w=3$, ‏$y=1$. אחרי קבלת הוקטורים של השכנים: ‏$D_x(w)=\min\{3,\;1+1\}=2$ (דרך $y$), ‏$D_x(z)=\min\{3+5,\;1+2\}=3$ (דרך $y$). הוקטור של $x$: $u=1$, ‏$v=2$, ‏$w=2$, ‏$y=1$, ‏$z=3$.

**LS מול DV:** ב-LS כל נתב צריך את הגרף כולו ומחשב Dijkstra; ב-DV נתב מכיר רק שכנים ומחליף וקטורים, ונדרשת התכנסות. DV איטי להגיב לשינויי עלות (ידוע בבעיית "ספירה לאינסוף").

## ניתוב בין רשתות: AS ו-BGP

- **רשת אוטונומית (AS):** קבוצת נתבים תחת ניהול אחד. **Intra-AS** (למשל OSPF): כל הנתבים בה מריצים אותו פרוטוקול. **Inter-AS:** ניתוב בין AS-ים, ובו כל ה-AS-ים מריצים **BGP**.
- **BGP** מפרסם **קידומות** יחד עם **תכונות** (AS-PATH, ‏NEXT-HOP), הוא פרוטוקול **path vector**, ושני נתבים מחליפים הודעות על חיבור **TCP**. כל AS מחליט בעצמו אילו נתיבים לקבל ולהפיץ.
- **בחירת מסלול ב-BGP:** קודם **מדיניות** (ערך local preference: יחסים עסקיים בין ספקים ללקוחות, "לא להעביר תעבורת מעבר שלא משלמים עליה"), אחר כך AS-PATH הקצר ביותר, אחר כך הנתב הקרוב ביותר (hot potato). לכן **השיקול המרכזי הוא מדיניות** ולא רוחב פס, השהיה או חשמל (26A-A שאלה 12).

## מלכודות

> 🪤 **"נתיב טוב = הכי מהיר".** ההגדרה היא עלות מינימלית לפי משקלים מופשטים שמייצגים כל מטריקה (25A-B שאלה 11).

> 🪤 **BGP אינו "הקצר ביותר".** הוא נשען על מדיניות.

> ⚠️ **ב-Dijkstra לא חוזרים לצומת סופי.** רק צמתים שעדיין לא ב-$N'$ מתעדכנים.

> ⚠️ **ב-Relaxation לוקחים את המינימום**, לא את הסכום ולא את הערך הישן אוטומטית.
